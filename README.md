## Meet the Team
A web application built with Next.js that introduces our team members, their roles, skills, and backgrounds. This project provides a clean and responsive interface for showcasing team information.

## Features
- View team member profiles
- Display names, roles, skills, and descriptions
- Responsive design for desktop and mobile devices
- Built with modern web development practices using Next.js

## Technologies Used
- Next.js – React framework for building the web application
- React – Frontend UI library
- JavaScript / TypeScript – Application logic
- CSS / Tailwind CSS – Styling and layout
- Git & GitHub – Version control
